# ChatGit 开发进度

## 2026-10-12：画布研究对话（新界面）

按 [设计决定](docs/canvas-design.md) 实现第一版，`/` 与本机启动器、Web Portal 都进入新界面 `/canvas/`。

**已经可用**

- 自有图数据模型：画布（含草稿、阅读位置、所选模型）与问答节点，存于 MongoDB 的 `chatgit_canvases`、`chatgit_nodes`，按用户隔离。
- 服务端上下文编排：来源路径并集、共同历史只发一次、旁支排除、划词原文随问题发送；长路径用节点摘要替换较早的轮次（直接来源与没有摘要的轮次保留原文）。界面可展开查看“下一问会带上”。
- 流式生成（SSE），关闭或刷新页面后在服务端继续并保存；停止保留已生成部分；失败显示原因并可重试；回答后自动生成摘要与 3 个推荐提问（仅作按钮，不自动展开分支）。
- 交互：从上到下的画布（平移、缩放、适配、路径高亮）；三种视图；划词浮窗（Enter 立即分支、Ctrl/⌘ + Enter 加入草稿、Ctrl/⌘ + Shift + Enter 新草稿）；多个草稿（输入框标签切换、改名，原文 A1/B2 编号，画布虚线节点）；右键菜单；Shift 多选合并；一次问多个并行；删除节点及后续（确认）；画布重命名、删除。
- 模型连接：OpenAI 兼容服务的地址与密钥、ChatGPT 订阅授权，在新界面的设置里完成；按画布选择模型。
- 全部界面用 Arc UI（含 Pro，见 `app/ARC_UI.md`）；简体中文、繁体中文、英文；浅色与深色。

**实际验证**

- `npm run check:safety`、六步受保护构建（新增 `web` 步骤）、`npm run test:safety` 35 项通过；上下文编排单元测试 14 项通过；前端类型检查与译文覆盖检查通过。
- 隔离的本机实例 + 本地假模型（不调用外部模型），通过真实启动器进入，在浏览器中实际操作并核对假模型收到的请求：首问、划词立即分支（2 条并行）、加入草稿并作为一个分支发送、Shift 多选合并（共同起点只出现一次、未选的 JEPA 旁支未出现）、失败后重试、停止、生成中刷新、刷新后草稿与阅读位置恢复、设置中保存与移除 OpenAI 兼容连接、深色与英文界面。
- 修复了验证中发现的问题：响应压缩缓冲了 SSE，导致回答要等全部完成才出现（已加 `no-transform` 并逐段 flush）；模型失败时重试过久（改为最多重试 1 次）。

**尚未完成或未验证**

- 附件、语音输入、旧会话导入尚未接入新界面；旧 LibreChat 界面仍可从 `/c/new` 打开。
- 真实模型服务与真实 ChatGPT 账号授权、推理未联调；验证用的是本地假模型。
- 合并节点的布局把节点放在最深的来源下面，来源相距较远时连线较长。
- 未做屏幕阅读器、触屏与性能测量；部分 Arc 组件仍有英文的读屏文字。

## 2026-10-09：基于 LibreChat 的第一阶段
更新：2026-10-09。本次是基于 LibreChat 的第一阶段可运行实现，不是完整产品发布。本文记录实现与验证情况，提交及推送状态以仓库记录为准。

### 当前可使用的流程

- `app/` 使用固定版本 LibreChat，复用数据库、模型连接、流式聊天和消息分支；旧 Next.js 源码保留在 `legacy/chatgit/`，不再作为运行入口。本机默认免注册，内部仍保留会话与内容归属校验。
- 同一会话可切换线性聊天与消息画布。支持保留当前问题继续分支，以及改写问题创建同级分支；原有回答不会被覆盖。
- 多选已完成的文字节点后提问。服务端按来源还原各自历史，共同内容只发送一次，未选的旁支不会混入。每次引用保存当时的完整文字，可在阅读区回看，后续追问继承引用。
- 引用内容超限、被裁掉或需要摘要替代时阻止发送，不悄悄丢弃用户选过的背景。
- 阅读区默认在侧边，可切换为弹窗；偏好保存在当前浏览器。窄屏上下排列，整图需要缩放后阅读节点。
- 关闭无关的产品入口；暂时保留上游源代码，不进行破坏性删除。模型连接支持用户自填 OpenAI-compatible 地址/密钥，以及可选的官方 ChatGPT 授权，不默认使用测试模型。
- Node 24.16.0 与 MongoDB 由根目录受保护入口管理；安装、构建、运行共用单任务锁，保留资源上限和退出清理。

### 本机免注册与 ChatGPT 授权

- 本机运行后用 `npm run open` 打开浏览器，不填写邮箱或密码。私有启动密钥换取一次性入口，刷新后沿用正常会话；直接打开登录/注册地址只显示本机启动说明。
- 空数据库自动建立内部本机所有者；已有账号但没有本机绑定的数据库不会被自动接管。旧数据与密钥保留，原账号模式通过 `CHATGIT_LOCAL_MODE=false` 使用。
- 设置 → Data & Privacy → Model connections 提供 Continue with ChatGPT，使用与 Codex 相同的 ChatGPT 账号，但不是复用 Codex 登录文件或客户端身份。只支持一个本机连接；授权由用户在 OpenAI 官方页面完成。
- 已实现授权身份校验、轮换令牌刷新、断开与撤销、真实账号模型列表、官方 Responses 请求适配。ChatGit 仍负责整理上下文，不把画布直接原样发送，也不因额度不足自动切换到 API 计费。
- 远程 orb 预览保持账号保护，不开放本机免注册身份或 ChatGPT 授权入口；当前不是桌面安装包。数据保存在运行程序的设备，orb 预览的数据不在用户电脑。

### 本阶段实际验证

- `npm run check:safety`、受保护的五步 `npm run build` 通过。
- `npm run test:safety`：35 项通过，包含进程数、重复启动拒绝、进程组退出清理、本机模式与启动器。
- 上下文与中止保存检查：19 项通过；聊天客户端与中止逻辑：317 项；消息与恢复请求：210 项；页面标题：9 项。合计 576 项针对性检查通过。
- Chromium 浏览器回归：1 条完整流程通过，覆盖注册、两种分支、多选引用、实际 HTTP 请求中的去重与旁支排除、刷新恢复、后续追问、停止、文字上传、阅读设置、键盘和窄屏输入。截图已检查浅色、深色、弹窗和 390px 视口。
- 客户端、data-provider、data-schemas 完整类型检查通过；API 改动的限定范围类型检查通过。完整 API 类型检查超过 2 GiB 单进程堆上限，未放宽保护，不宣称完整检查通过。
- 未运行上游 Lighthouse 性能检查：其默认启动流程绕过本项目受保护入口。未完成全平台性能验收。

新增免注册/模型授权检查：后端 103 项、数据库 129 项、相关客户端 48 项通过；本机访问与 ChatGPT 自定义模型接入的限定范围类型检查通过。独立本机数据库上的 Chromium 回归通过，覆盖免注册进入、刷新、重复入口拒绝、无密钥提示、授权地址/取消/拒绝后重试，以及模拟已连接状态的模型列表和断开；检查了浅色、深色和 390px 窄屏截图。真实 OpenAI 登录授权与模型推理尚未联调，不能把模拟通过当成真实账号可用证明。

画布回归使用本地固定回复服务；免注册与授权界面回归不调用外部模型。检查的是界面行为、保存结果和请求，不是大模型回答质量。复现方法见 [浏览器验证说明](app/e2e/chatgit/README.md)。

### 明确边界

- 第一阶段仅支持引用已完成的纯文字分支；含文件、图片、工具调用或未完成回答的历史不能作为画布来源。普通聊天保留文字文件上传。
- 当前限制为 12 个来源、200 条快照消息、20 万存储字符、4.8 万渲染引用字符；超限拒绝，不自动摘要。
- 暂未实际联调用户的真实模型服务或 ChatGPT 订阅授权；后者取决于账号资格和 OpenAI 开放情况。上游恢复执行的引用保护只检查结构，工具与人工审批等入口保持关闭。
- 新增界面文案遵循上游规则只增加英文键，中文界面文案尚未补全。
- 旧版浏览器内的会话记录尚未导入新数据库；没有删除旧浏览器数据。
- 测试账号与固定回复配置只用于验证，不作为用户默认数据或模型连接。
