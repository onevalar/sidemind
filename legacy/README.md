# legacy/

合并前的两个旧产品，仅供参考，不再维护；它们的提交历史完整保留在本仓库的 Git 历史中。

- `chatgit-librechat/`：基于 LibreChat 的 ChatGit（原仓库根目录的全部内容，包括 `app/`、`docs/`、`scripts/`）。它的脚本和 Amp 配置按原仓库根目录的路径编写，挪到这里后不能直接运行；需要时请把它检出到原位置（`git log` 里 Sidemind 合并之前的提交）。
- `chatgit-nextjs/`：更早的 Next.js 版 ChatGit。

Sidemind 的代码在仓库根目录：`web/`（Web 版）、`SidemindApp/`（原生原型）。
