# Sidemind

**Sidemind = side + mind，“在你旁边的另一颗头脑”。** 在笔记里阅读和写作时，随时在旁边岔出一条线去研究；想清楚了，再有选择地收回到正文。由原来的 Canvas Note 与 ChatGit 合并而成。

| 路径 | 内容 |
| --- | --- |
| `web/` | Sidemind Web 版（Node 服务 + React 界面），在本机起服务、用桌面浏览器使用。说明见 [web/README.md](web/README.md) |
| `本机试用指南.md` | 安装、启动、试用流程、备份与导入旧数据 |
| `Sidemind-产品计划-v1.md`、`Sidemind-开发计划-v1.md`、`Sidemind-M0-兼容与基线.md` | 产品与开发计划 |
| `SidemindApp/` | 原生 macOS 原型（未随 Web 版演进） |
| `legacy/` | 合并前的 ChatGit（LibreChat 版与 Next.js 版），仅供参考 |
| `PRD-v0.1.md`、`技术架构设计-v0.1.md`、`技术路线-*.md` | 合并前的历史设计记录 |
