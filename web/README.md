# 画布笔记 Web 版

一个在浏览器里使用的 Markdown 笔记应用：每篇笔记是真实的 `.md` 文件，每个块是画布上的一张卡片。
设计依据见仓库根目录的 `技术路线-v0.2-Web.md`。

## 运行

```sh
npm install
npm run dev        # 同时启动笔记服务（3001）和网页（5173）
```

打开 http://localhost:5173 。

- 笔记文件夹默认是 `web/workspace`，可用环境变量 `NOTES_DIR=/你的/笔记目录` 指定。
- 工作台和设置中的“打开文件夹”会在运行本地服务的电脑上打开当前 Markdown 工作区：macOS 使用 Finder，Windows 使用资源管理器，Linux 使用系统文件管理器。系统无法打开时会显示错误，可在设置中查看工作区路径并手动打开。
- 卡片位置保存在笔记文件夹下的 `.canvasnote/<笔记>.board.json`，不会改动 `.md` 正文。
- 用任何其他编辑器修改 `.md` 文件，画布会实时刷新。

## 其他命令

```sh
npm test           # 单元与接口测试
npm run typecheck
npm run build && npm start   # 生产方式：单进程同时提供网页和接口
```

## Amp 开发环境

仓库根目录的 `.agents/setup` 使用 orb 预装的 Node.js/npm，按锁文件安装全部开发依赖；不启动服务、不清空笔记、不保存登录凭据。当前已验证 Node 26.10.0；安装会检查依赖所需的 Node 版本，不兼容时明确失败。

预览服务在 `.amp/services.yaml` 中声明。新 orb 打开 Portal 时，Amp 会启动缺少的服务；也可从仓库根目录执行：

```sh
./.agents/setup             # 手动重新准备依赖；新 orb 通常自动执行
amp orb services ensure    # 启动/检查预览，并输出当前环境的预览链接
```

API 固定使用本机端口 3001，网页使用 5173 并代理 API；健康检查验证网页到 API 的完整读取路径。服务由 Amp 管理，重复 ensure 不会启动副本；无需额外的 `.agents/resume` 重启脚本。

示例笔记位于根目录 `.amp/preview-notes`，连接设置位于 `.amp/preview-config`；重新准备和启动不重置已有数据。数据、凭据和自动生成的 portal 文件不提交到 Git；只提交服务定义，链接由 Amp 为当前环境生成。

配置需要进入项目默认分支后才会用于之后的新 orb；只有本地提交并不代表已经启用，也可改用 Amp 项目的启动前配置。当前连续运行 setup 两次约 16 秒/15 秒，重复 ensure 返回两个服务 HTTP 200，111 项测试、类型检查及构建通过；现有依赖配套版本警告和构建体积提示仍保留，未在环境配置中强制升级或屏蔽。

## 安全说明

服务可以读写本机文件且没有登录，所以只监听 `127.0.0.1`，只接受发往 localhost 的请求，
并且写操作只接受 JSON。不要把它直接暴露到公网。

## 当前功能

工作台快速记录、空间分类、标题与正文搜索、文档阅读和 Markdown 编辑、画布卡片拖动、
纵向容器（拖入、排序、解散）、浅色/深色/系统外观，以及外部文件修改通知。
“最近打开”按实际访问排序，时间保存在工作区的独立元数据中，不改变 Markdown 的修改时间。
工作台分别展示“继续上次的思考”和“最近更新”；前者按实际访问排序，后者按文件修改时间排序。
快速记录可选择保存空间、引用已有笔记；引用写为普通 Markdown 相对链接，文档与画布内点击可打开原笔记。
搜索使用定制库的 Command 组件，支持所有笔记/空间分类、正文搜索、方向键选择、Enter 打开和 Esc 关闭。
空关键词会展示已有笔记；输入变化、关闭搜索或切换分类时取消旧请求。⌘/Ctrl K 打开搜索，⌘/Ctrl N 新建笔记。
文档目录会跟随未保存的草稿更新；阅读和编辑时均可点击目录定位，支持六级标题。
编辑时可在新行输入 `/`，用方向键与 Enter 插入标题、引用、列表、待办、代码块或分隔线，Esc 关闭；代码块内不弹出插入菜单。
选择单行文字可加粗、斜体、插入行内代码或链接；⌘/Ctrl B、I、K 对应加粗、斜体、链接，未选择文字时 ⌘/Ctrl K 仍打开搜索。
插入与格式修改均为独立的一步撤销，正文仍为普通 Markdown。链接插入后会选中示例网址，便于直接替换。
保存使用原子写入和内容版本检查；遇到外部修改时保留草稿并阻止旧内容覆盖新文件。
编辑内容及应用 AI 建议后可撤销，撤销历史仅保留在当前打开的笔记会话中。

AI 助手可在“设置与外观”中填写 OpenAI 兼容服务的地址、模型名称和 API 密钥，
先测试连接，再保存；不需要重启服务。切换服务地址时必须重新填写密钥，不会把旧服务的密钥发给新地址。
测试只发送一条简短测试消息，不读取笔记，也不自动保存填写的设置。

连接按工作区路径分开保存在本机配置目录，位于笔记文件夹之外：macOS 使用
`~/Library/Application Support/CanvasNote/connections`，Windows 使用 `%APPDATA%/CanvasNote/connections`，
Linux 使用 `$XDG_CONFIG_HOME/canvas-note/connections`（默认 `~/.config/canvas-note/connections`）。
可用 `CANVAS_CONFIG_DIR` 指定独立配置目录。目录和文件在支持 POSIX 权限的平台分别使用 0700、0600；
密钥是本机的私有配置，不是系统钥匙串加密存储。已保存的密钥不会返回网页或写入浏览器存储。
移除连接会清除该文件里的密钥，并保留断开状态，避免重启后回退到旧环境变量中的密钥。

仍兼容启动时提供 `CANVAS_AI_API_KEY`（或旧名称 `CANVAS_AI_KEY`）、`CANVAS_AI_MODEL` 和可选的
`CANVAS_AI_BASE_URL`。界面保存的设置优先；远程地址需要 HTTPS，本机服务可使用 HTTP。
仅在点击发送时将选中的文字、内容块或整篇笔记交给配置的服务，
先显示原文和修改预览，确认后才写回 Markdown，并可撤销。预览聚焦改动所在的片段，
折叠未变化的首尾内容，完整原文与建议仍可展开查看。生成和连接测试均可停止。
未配置时展示连接入口，不生成模拟结果。

Web 控件使用 vendor/onevalar-pro-1.0.0-beta.10.tgz，由用户的 Hero UI v3 custom
源码构建，主题采用库内 Linear tokens。更新定制库时需重新构建并替换该快照。
