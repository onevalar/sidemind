# 画布笔记 Web 版

一个在浏览器里使用的 Markdown 笔记应用：**画布上的一张卡片是一篇完整文章，不是文章中的段落。**
每个真实文件夹对应一个画布；文章正文是普通 `.md` 文件，位置独立保存。
设计依据见仓库根目录的 `技术路线-v0.2-Web.md`。

## 运行

```sh
npm install
npm run dev        # 同时启动笔记服务（3001）和网页（5173）
```

打开 http://localhost:5173 。

- 笔记文件夹默认是 `web/workspace`，可用环境变量 `NOTES_DIR=/你的/笔记目录` 指定。
- 右键侧栏中的文件夹，选择“在文件管理器中打开”，在运行服务的电脑上打开所选文件夹，不切换当前画布；顶部不设独立按钮。在远程 orb 中不会打开你电脑上的文件夹。
- 文章位置、文档区和最近打开记录保存在 `.canvasnote/library.json`，不会改动 `.md` 正文或文件修改时间。
- 可使用其他编辑器修改正文，网页会同步标题、摘要和正文，位置不会改变。
- 远程 orb 预览使用独立的示例笔记，不能读取你自己电脑的文件。

## 其他命令

```sh
npm test           # 单元与接口测试
npm run typecheck
npm run build && npm start   # 生产方式：单进程同时提供网页和接口
```

## Amp 开发环境

仓库根目录的 `.agents/setup` 使用 orb 预装的 Node.js/npm，按锁文件安装全部开发依赖；不启动服务、不清空笔记、不保存登录凭据。当前已验证 Node 26.10.0；安装会检查依赖所需的 Node 版本，不兼容时明确失败。

预览服务在 `.amp/services.yaml` 中声明。新 orb 打开 Portal 时，Amp 会启动缺少的服务；也可从仓库根目录执行：

```sh
./.agents/setup             # 手动重新准备依赖；新 orb 通常自动执行
amp orb services ensure    # 启动/检查预览，并输出当前环境的预览链接
```

API 固定使用本机端口 3001，网页使用 5173 并代理 API；健康检查验证网页到 API 的完整读取路径。服务由 Amp 管理，重复 ensure 不会启动副本；无需额外的 `.agents/resume` 重启脚本。

示例笔记位于根目录 `.amp/preview-notes`，连接设置位于 `.amp/preview-config`；重新准备和启动不重置已有数据。数据、凭据和自动生成的 portal 文件不提交到 Git；只提交服务定义，链接由 Amp 为当前环境生成。

配置需要进入项目默认分支后才会用于之后的新 orb；只有本地提交并不代表已经启用，也可改用 Amp 项目的启动前配置。当前连续运行 setup 两次约 16 秒/15 秒，重复 ensure 返回两个服务 HTTP 200，111 项测试、类型检查及构建通过；现有依赖配套版本警告和构建体积提示仍保留，未在环境配置中强制升级或屏蔽。

## 安全说明

服务可以读写本机文件且没有登录，所以只监听 `127.0.0.1`，只接受发往 localhost 的请求，
并且写操作只接受 JSON。不要把它直接暴露到公网。

## 当前功能

- **多文章画布**：默认显示标题、正文的纯文本摘要和文件名。拖动卡片自由摆放，选中后方向键每次移动 20 个画布单位；平移、缩放、查看全部只改变视角，不排列文章。
- **文档区**：右键文章，在菜单中选择“创建文档区”；按住 Shift 再右键其他文章可以多选后一起创建，只包含明确选中的文章。其他文章拖到区域正文范围内、卡片中心进入后自动加入；区域随成员自动扩展或收缩，不挪动其他文章。拖出后脱离；拖动区域标题或聚焦后用方向键整组移动，经过其他文章不自动收纳。支持改名、拖动右下角调整大小，不能缩小到盖不住已有成员；“解散文档区”保留文章、正文和所有当前位置。区域不嵌套，同一文件夹内一篇文章最多属于一个文档区，不移动真实文件。
- **位置稳定**：修改标题、正文或文件修改时间，以及新增文章、重新打开、重启服务，都不会重新排列已有文章。只有新文件分配初始位置，放在已有文章下方；外部重命名或移动文件目前按新路径视为新文章。
- **打开与预览**：单击选中，空格只读预览，双击或 Enter 打开编辑器；文章右键菜单也提供“预览文章”和“打开并编辑”。Esc 关闭预览并恢复焦点。
- **单篇编辑**：默认使用成熟开源的 [Milkdown Crepe](https://github.com/Milkdown/milkdown)（MIT，基于 ProseMirror）。直接在排版后的正文里修改标题、粗体、引用、列表、待办、表格和代码块，不设格式工具栏、斜杠菜单、分栏或阅读切换。输入 `# `、`## ` 创建标题，`**文字**` 转为粗体。正文行宽最多 720px，文字左对齐，左右留白自适应；滚动区域铺满可用工作区，不在正文旁放置窄滚动框。保存状态、手动保存和撤销在底栏。编辑器、字体和样式由本地服务提供，不依赖在线编辑器或 CDN。
- **源码与保真**：保留 `@uiw/react-md-editor` 作为无工具栏的源码入口。打开文章或仅切换编辑方式不会改写文件；实际富文本修改会重新生成 Markdown，可能统一列表符号、空行和表格空格，额外空段落采用 `<br />`。需要逐字符保留写法时请使用源码。YAML/TOML frontmatter、引用式链接、脚注、原始 HTML（独立空行标记除外）及代码块元数据自动使用源码，避免静默丢失结构。暂不提供图片粘贴/拖入上传或数学公式渲染。
- **长文定位**：两种编辑方式均保留跟随草稿更新的六级目录，点击定位对应标题。目录默认收起，通过顶部“目录”展开右侧面板；关闭按钮和 Esc 均能真正关闭，并把焦点返回入口。正文在剩余空间居中。源码切回时恢复原有光标、选区方向和滚动位置；写作视图重新打开时从正文开头开始。切换方式会清除 AI 选区，避免两种编辑器的位置混用。正文链接使用 Ctrl/⌘ 点击，或悬停后点击链接地址打开；相对 `.md` 链接在应用内跳转。
- **新建与引用**：新建真实文件夹、选择文章所在文件夹、快速输入正文、引用已有文章。引用是可迁移的相对 Markdown 链接，支持安全的同目录、子目录、父目录跳转。
- **搜索与最近打开**：搜索标题、正文、文件夹；方向键/Enter 选择，Esc 关闭。⌘/Ctrl K 打开搜索（编辑器内该组合键由编辑器处理）；⌘/Ctrl N 新建，⌘/Ctrl S 保存。最近打开按真实访问记录排序，不用文件修改时间替代。
- **保存保护**：自动保存、离开前等待最新草稿保存、原子写入、写前内容核对。外部编辑冲突时保留草稿，不用旧正文覆盖新文件。编辑器保存与 Agent 修改分别可撤销；接受外部新正文后清除旧保存撤销历史。位置保存失败保留待保存位置并提供重试，阻止离开丢失修改。
- **外观**：浅色、深色、跟随系统。左侧导航可折叠为工具窄栏，仍保留展开、搜索、新建、返回画布和设置入口；浏览器记住折叠状态。
- **AI Agent**：文件夹画布和文章页共用 Arc `ai-composer` 助手，支持普通对话、讨论笔记、找关联、总结，以及明确要求后的直接编辑、整理和合并。可选择当前文章、整个文件夹（含子文件夹）或纯聊天；纯聊天不提供笔记、文件名或文件工具。不同范围分别保存连续对话，导航或隐藏面板不丢记录；刷新页面开始新对话，服务重启后旧会话需重新开始。
- **助手分栏**：使用 Arc `resizable-panels` 拖动画布/文章与助手之间的分界，聚焦分界后也可用方向键调整，Shift 加方向键大步调整、双击恢复初始比例。浏览器记住分栏宽度，关闭或调整面板不重建编辑器、不丢草稿与选区。窄于 820px 的窗口使用覆盖式面板。Enter 发送，Shift+Enter 换行，中文输入法组词时不发送；快捷要求只填入输入框，不自动发送。

## AI 连接与边界

### ChatGPT 官方登录

设置中的 **Continue with ChatGPT** 使用 OpenAI 官方开源工具登录流程，支持符合条件的 ChatGPT 方案使用，不需要粘贴 API 密钥。
保存每个账号/工作区注册、读取可用模型、选择模型、刷新会话、重新登录、退出并尝试撤销授权。
只调用官方公共 Models / Responses 接口，不使用非官方 ChatGPT 后端接口，不读取聊天记录。

**必须在运行笔记服务的同一台电脑上打开浏览器完成登录。** 官方回调使用临时 `127.0.0.1` 端口；远程 portal 预览禁用登录，并说明原因。
实际可用性受账号方案、工作区政策、地区和额度限制。额度可在 https://chatgpt.com/settings/usage 查看。
登录失效、额度不足或配置损坏时，不会自动改用 API 密钥产生另一种费用；切换需手动选择。

本轮用模拟官方服务、真实本机 HTTP 回调和签名校验测试授权、刷新、退出和流式结果；**尚未使用真实 ChatGPT 账号完成授权和模型调用验收**。

### 其他模型服务

也可填写 OpenAI 兼容地址、模型名称和 API 密钥，测试后保存，无需重启。讨论和编辑笔记需要模型支持工具调用（function calling）；不支持的模型只能纯聊天。
切换服务地址必须重新填写密钥，不会把旧密钥发给新地址。测试只发送简短测试消息，不读取笔记，不自动保存设置。

连接按工作区路径分开保存在本机配置目录，位于笔记文件夹之外：macOS 使用
`~/Library/Application Support/CanvasNote/connections`，Windows 使用 `%APPDATA%/CanvasNote/connections`，
Linux 使用 `$XDG_CONFIG_HOME/canvas-note/connections`（默认 `~/.config/canvas-note/connections`）。
可用 `CANVAS_CONFIG_DIR` 指定独立配置目录。目录和文件在支持 POSIX 权限的平台分别使用 0700、0600；
密钥是本机的私有配置，不是系统钥匙串加密存储。已保存的密钥不会返回网页或写入浏览器存储。
移除连接会清除该文件里的密钥，并保留断开状态，避免重启后回退到旧环境变量中的密钥。

仍兼容启动时提供 `CANVAS_AI_API_KEY`（或旧名称 `CANVAS_AI_KEY`）、`CANVAS_AI_MODEL` 和可选的
`CANVAS_AI_BASE_URL`。界面保存的设置优先；远程地址需要 HTTPS，本机服务可使用 HTTP。
每篇文章的概述、目录和正文版本保存在本地 `.canvasnote/overviews.json`，不写入 Markdown 或改变画布位置。初始概述是本地摘录，Agent 按需读完全文后可记住语义概述；正文变化会使旧概述失效并重建。不会在后台自动把整库交给模型。

只有点击发送后才请求明确选择的模型。Agent 先看当前范围内的概述，再搜索、分页读取相关原文，连续对话会带上此前这个范围内的交谈与已读资料。普通问候、提问和总结默认只回复；明确要求修正、整理或合并时才写入，操作意图由模型遵守指令判断。后端强制限制文件范围、读取版本和完整读取后才能整篇重写；精确替换保留未涉及的文字和换行。发送文件任务前会先保存当前草稿。合并默认新建文章，不删除或覆盖来源。

已有文章的每次修改先备份前后正文到 `.canvasnote/agent-changes/`，再写入文件。可查看差异并撤销，刷新或服务重启后仍能找回当前版本的可撤销修改。撤销前核对正文，拒绝覆盖更新的手动修改。生成和连接测试均可停止；停止或后续步骤失败不会回滚已完成的操作，须检查修改记录。未配置时展示连接入口，不生成模拟结果；被截断的模型回复不会执行工具。

### 首屏资源优化

画布先加载，编辑器代码和样式在画布就绪后的浏览器空闲时预加载；首次立即打开也会等待同一份编辑器资源，不绕过离开前保存保护。使用 uiw 官方 `nohighlight` 入口：普通编辑或没有代码块的预览不下载语言规则，含代码块的分栏预览再按需加载完整语言支持。保留安全 HTML、表格、格式命令、链接及目录定位；加载失败提示不会遮住正文或保存入口，未着色代码仍可读写。

生产服务对 `/assets/*` 启用协商压缩，笔记接口与实时事件流不压缩；现有开发预览仍使用 Vite，不用于下面的生产性能对比。

本轮优化前后生产构建使用同一 Chromium、2340×1254、2× 像素密度、十篇隔离文章，每轮清缓存，模拟 180ms 网络延迟、10Mbps 下载和 CPU 4× 减速，前后交替各测五次。耗时取中位数，资源量是浏览器记录的 JavaScript + CSS 实际传输字节，含请求开销。

| 项目 | 优化前 | 优化后 |
| --- | --- | --- |
| 首次导航到画布可用 | 3247.7ms | 1067.7ms |
| 画布可用时已传输资源 | 1,948,515 字节 | 280,090 字节 |
| 包括编辑器空闲预加载的资源 | 1,948,515 字节 | 382,234 字节 |

## 界面组件

Web 界面使用 [Arc UI](https://uiarc.dev)：按钮、输入框、多行输入、选择框、弹窗、提示、页签、分段切换和搜索面板。

`components.json` 保留安装配置，例如 `npx shadcn@latest add @uiarc/button`。旧 Onevalar/Hero UI 快照不再作为运行依赖。

本地适配包括中文提示、输入框支持外部标签、嵌套弹窗的焦点恢复，以及搜索面板的受控查询、服务端全文搜索和中文输入法保护。设置页签切换保留未保存输入。更新组件时不要直接覆盖这些适配。
