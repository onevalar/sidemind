# 画布笔记 Web 版

一个在浏览器里使用的 Markdown 笔记应用：每篇笔记是真实的 `.md` 文件，每个块是画布上的一张卡片。
设计依据见仓库根目录的 `技术路线-v0.2-Web.md`。

## 运行

```sh
npm install
npm run dev        # 同时启动笔记服务（3001）和网页（5173）
```

打开 http://localhost:5173 。

- 笔记文件夹默认是 `web/workspace`，可用环境变量 `NOTES_DIR=/你的/笔记目录` 指定。
- 卡片位置保存在笔记文件夹下的 `.canvasnote/<笔记>.board.json`，不会改动 `.md` 正文。
- 用任何其他编辑器修改 `.md` 文件，画布会实时刷新。

## 其他命令

```sh
npm test           # 单元与接口测试
npm run typecheck
npm run build && npm start   # 生产方式：单进程同时提供网页和接口
```

## 安全说明

服务可以读写本机文件且没有登录，所以只监听 `127.0.0.1`，只接受发往 localhost 的请求，
并且写操作只接受 JSON。不要把它直接暴露到公网。
